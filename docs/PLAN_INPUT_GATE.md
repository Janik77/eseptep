# Проверка входных планов (кандидат к #86)

- В форме «Загрузить и рассчитать» принимает PDF, JPEG/JPG, PNG и WebP, до 5 МБ, до 12 страниц PDF и до 20 Мп на изображение. Имя файла и браузерный MIME не подтверждают формат: сервер проверяет сигнатуру, декодирование и существующий запрет активных/вложенных частей PDF. Неподдерживаемый файл не создаёт попытку ИИ. Для изображений сохраняются пересобранные пиксели без служебных данных с учётом EXIF-ориентации; подготовленный файл также ограничен 5 МБ. Разрешённая прежняя ручная загрузка не расширяется.
- Пустое изображение или PDF с однозначным первым заголовком фасада/разреза с номером/осями на всех страницах отсекаются локально без внешнего запроса. В смешанном PDF явно неподходящие и пустые страницы не отправляются; номера остальных сохраняются. Слабые признаки не используются для автоматического отказа. Фото самого чертежа допустимо. Файл и ручной ввод остаются доступны при семантическом отказе.
- Для неоднозначного содержимого один ограниченный запрос классифицирует документ и извлекает данные только при наличии планировки; второй платный проход не нужен. Если ответ обозначает фото/фасад/другое/неуверенность, смета по ИИ не создаётся; принимаются только комнаты допустимых страниц. Нельзя гарантировать бесплатный отказ для всякой фотографии: запрос, нужный для семантической проверки, может быть тарифицирован. Реальных платных вызовов в проверке этой ветки не было.
- Приватная история связывает версию распознавания, область пользователя/гостевой сессии, SHA-256 исходной загрузки и сохранённых байтов. Смена имени/языка/перезагрузка не повторяют попытку. Уникальная запись резервируется до вызова; её незавершённое или неизвестное состояние не запускает авто-повтор. Ручные правки остаются у конкретной сметы, не становятся результатом распознавания повторной копии. Другим аккаунтам ничего не переиспользуется. В защитный локальный журнал бюджета передаётся только непрозрачный разделитель; он не включается в отправляемые провайдеру данные.
- Для старых записей без исходного SHA не выдумывается отпечаток оригинала. Если обнаружена точная запись по предыдущему отпечатку сохранённых байтов, старые комнаты не подмешиваются, новый запрос не запускается. Уже сохранённая смета остаётся доступной. Явный перенос гостевого расчёта при входе не даёт доступ к любому чужому ID. Новый формат распознавания не меняет версию сохранённых смет, расчётные формулы и настройки платежного лимита.

Локальный просмотр/распознавание дополнительно ограничивает размер декодированных инструкций PDF (2 МБ на страницу, 8 МБ суммарно) поверх штатной защиты pypdf; слишком сложный файл переводится на ручной путь, а не отправляется провайдеру. Это не обещание полного распознавания произвольного PDF.
