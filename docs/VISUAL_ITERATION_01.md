# ESEPTEP: первая визуальная итерация

Основа: PR #69, `7bfd644a60a4acbbe504dcfd3176be57ee877569`.
На момент начала работы это оставался актуальный HEAD PR #69. Новая ветка
`ui/warm-renovation-first-iteration`. Main и production не изменялись.

## Границы

Только главная, каталог всех 12 калькуляторов и калькулятор плитки
`/calculators/plitka-keramogranit/`. Шаблоны, изолированные стили и взаимодействие
поиска/фильтров. Формулы, валидация, модели, права, сохранение и защита файлов
не изменены. Общий helper копирования теперь честно сообщает отказ браузера и возвращает фокус; переход к результату учитывает reduced motion. Остальные калькуляторы сохраняют прежний дизайн. Добавленные
атрибуты связи ошибки с полем улучшают доступность, не меняя POST.

## Визуальное решение

Тёплый фон, графит, терракота. Крупный интерьер и спокойный акцентный курсив
дают образ будущего пространства, а геометрические образцы дерева, плитки и
краски связывают его с реальными видами расчёта. Каталог использует авторские
inline SVG по видам работ и короткое «ввод → результат» вместо одинаковых
абзацев. Калькулятор связывает форму и список общей сеткой. Успех копирования
не меняет высоту содержимого. Цены/пример/AI-интерьер обозначены честно.

Изученные референсы, не скопированные шаблоны:
- [Sweeten](https://sweeten.com/): интерьер как первый смысловой образ и ясное
  основное действие, далее короткая последовательность шагов.
- [Havenly](https://havenly.com/): визуальный процесс и комнатные сцены вместо
  стены текстовых карточек.
- [Houzz](https://www.houzz.com/US): узнаваемые категории и предметная навигация.
- [Calculator.net Tile](https://www.calculator.net/tile-calculator.html):
  размерности и понятная связь входных параметров с результатом, не его стиль.

Фото hero создано специально как AI-концепция, локальный WebP, 236582 байта.
Размеры зарезервированы до загрузки. Источник/prompt: `static/images/PROVENANCE.md`.
Иконки и графика материалов авторские CSS/SVG. Новых CDN/JS-библиотек нет.
Существующее подключение Inter через Google Fonts осталось; при недоступности
работает системный кириллический шрифт.

## Обновление отдельной локальной копии

Не переключайте main или несохранённую рабочую копию. Из существующего clone:

```bash
git status --short
git fetch origin ui/warm-renovation-first-iteration
git worktree add --detach ../eseptep-visual-review origin/ui/warm-renovation-first-iteration
cd ../eseptep-visual-review
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export DJANGO_ENV=development DJANGO_DEBUG=true
export DJANGO_DB_PATH="$PWD/review.sqlite3"
export DJANGO_PRIVATE_MEDIA_ROOT="$PWD/private_media"
export DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost
python manage.py migrate --noinput
python manage.py runserver 127.0.0.1:8000
```

Команды рассчитаны на Ubuntu/WSL bash (в том числе терминал PyCharm с WSL),
не PowerShell. Если каталог `../eseptep-visual-review` уже существует, не
удаляйте его: выберите другое новое имя. Для просмотра открыть
`http://127.0.0.1:8000/`, `/calculators/`, `/calculators/plitka-keramogranit/`.

Для проверки сохранения зарегистрируйте отдельного тестового клиента и
создайте проект в кабинете. Введите параметры калькулятора, выберите вариант,
скопируйте список, явно выберите проект и сохраните. Восстановление/изменение
production-базы не требуется и не входит в эти команды.

## Проверки

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
node --test calculators/js_tests/*.test.cjs
git diff --check
```

Проверено: 49 Django-тестов, 9 Node-тестов, system check, отсутствие новых миграций и git diff --check.

Браузерная приёмка должна быть отражена отдельно с точными результатами,
не заменяться тестами Django или утверждением о готовности. На промежуточном
этапе локальный Chromium не смог запуститься из-за ограничения socket, а
облачный браузер не увидел локальный сервер. Это не ошибка сайта и не
доказательство, что визуальная проверка прошла.

## Сохраняющиеся ограничения исходной версии

См. `docs/INTEGRATION_REVIEW.md`: эта визуальная итерация не завершает проверку
строительных нормативов, legacy public uploads, production-конфигурации или
независимый security-review. Не применять к реальным клиентским данным как
проверенный production-релиз. Дизайн остальных страниц пока не распространяется
до просмотра владельцем первой итерации.
