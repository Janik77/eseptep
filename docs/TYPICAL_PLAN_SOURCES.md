# Типовые планы ESEPTEP
Все три схемы самостоятельно созданы для этого проекта генератором `tools/build_typical_plans.py` (18.11.2026). Чужие планы/фотографии не использованы. Исходный код и созданные материалы сохранены в репозитории по запросу владельца. Это демонстрационные конфигурации, не технический или строительный проект и не копии определённого ЖК.

Студия36м², двухкомнатная72м², трёхкомнатная99м². Стены, дверные проёмы, окна, подписи, размеры и экспликация включены. `tests/fixtures/plans/typical-manifest.json` хранит эталонные площади всех помещений для QA. Эталон не передаётся в Responses и не выдаётся за ответ модели. UI до анализа показывает только общую площадь и число комнат. Нечитаемый fixture оставлен для автоматических тестов, но убран из клиентского каталога.
