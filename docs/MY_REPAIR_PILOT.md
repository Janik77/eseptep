# Закрытый пилот «Мой ремонт»

Существующий проект клиента остаётся основным. Модуль добавляет согласованные
предложения по материалам и работам, версии условий, подтверждение поставок,
приёмку этапов, фотографии и рассмотрение проблем. Платежей, возвратов,
компенсаций, внешних уведомлений и обязательств о возмещении нет.

## Локальная проверка на синтетических данных

Установите зависимости репозитория в виртуальное окружение и из корня запустите:

```bash
python tools/run_my_repair_review.py
```

Скрипт печатает точную ссылку и данные синтетического клиента. Он не открывает
рабочую базу, не использует ключи OpenAI и слушает только 127.0.0.1:8241.
Временная SQLite-база и её вложения удаляются после остановки. Локальный URL
доступен только на той машине, где запущен процесс; мобильный вид можно открыть
в эмуляции браузера. Не публикуйте тестовый стенд в интернете.

## Где включить и выключить

После штатной установки этого релиза и применения миграций:

1. `/admin/` → **Мой ремонт** → **Города пилота «Мой ремонт»**.
   Добавьте «Шымкент» и включите **Пилот включён**.
2. Там же → **Проекты пилота «Мой ремонт»**. Добавьте только согласованный
   существующий проект клиента из того же города, назначьте ответственного
   ESEPTEP и отметьте **Доступ для этого проекта**.
3. Участники открывают раздел из своих кабинетов. Ответственный с ролью
   «Администратор» использует `/repair/review/`; видны только назначенные ему
   открытые проекты. Точный адрес доставки не выводится в его ленте.
4. Снимите флаг города или проекта, чтобы закрыть прямые ссылки, действия и
   фотографии. Это не удаляет договорённости и историю; повторное включение
   возвращает их. Добавление города само по себе не открывает ни одного проекта.

До назначения адреса используйте тестовые данные. После назначения адрес видит
клиент-владелец и выбранный поставщик в неполученной поставке; мастер и другой
поставщик его не получают. Фото пересохраняются без метаданных и доступны только
в пределах соглашения с повторной проверкой полномочий на каждом запросе. Не
публикуйте вложения через публичное медиа-хранилище.

Если магазин ещё не подтвердил количество, наличие и цену по всем выбранным
позициям, предложение нельзя перенести как согласованное. Сроки, которых нет в
исходном предложении, не считаются установленными; партнёр может предложить
уточнённые условия, действующие только после подтверждения клиента. Старые
версии сохраняются.
