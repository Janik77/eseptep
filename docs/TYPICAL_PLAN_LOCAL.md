## PyCharm
Открыть существующий проект. В верхнем списке Run выбрать **ESEPTEP Demo**, затем зелёный треугольник. Открыть http://127.0.0.1:8220/projects/upload/. Не запускать второй сервер на том же порту; красный Stop останавливает запущенную конфигурацию. Если список не обновился: Run → Edit Configurations → Python, script `tools/run_local.py`, рабочая папка проекта, interpreter существующей `.venv`. Для **ESEPTEP AI Pilot** добавить параметр `--ai`. Готовые конфигурации хранятся в `.run/` и не содержат секретов.

Ключ вводится владельцем только в существующий `.env`: `OPENAI_API_KEY`. Запуски не перезаписывают этот файл. Сам ключ не включает платные вызовы. AI Pilot проверяет отдельное сохранённое подтверждение остатка пилота; без него работает ручной сценарий. Общий лимит ESEPTEP остаётся $2, не баланс всего аккаунта. Один подтверждённый пробный запрос резервирует20центов; повтор формы/перезапуск не добавляет новый лимит. После использования разрешения другой новый платный запрос запрещён. Не удалять ledger, не восстанавливать старую базу ради новых попыток.

## Показ
Тестовый клиент `demo-client@example.test`, поставщик `demo-supplier@example.test`, пароль обоих `Demo-Meeting-2026!`. Только синтетические данные.

Загрузить свой план или раскрыть каталог типовых → выбрать схему → увеличить изображение при необходимости → отдельно «Проанализировать план» → проверить найденное помещение/страницу/подпись → подтвердить или исправить площадь → плитка на пол → вариант → проект → сохранить → PDF → подтвердить тестовую заявку → открыть её поставщиком. Если API выключен/ошибка/лимит, доступен ручной ввод. Смена языка не отправляет новый запрос. Прайс частичный и демонстрационный, не коммерческое предложение.

Сервер слушает только127.0.0.1. Телефонная композиция проверяется на390px в локальном браузере. Не обещается доступ с другого телефона по сети. До запуска сохраняется SQLite backup в `meeting-demo-data/backups/`, без удаления старых копий. Фотографии и прежние базы не сбрасываются.

Обычный запуск PowerShell: `.\.venv\Scripts\python.exe tools\run_local.py`; AI: та же команда с `--ai`. Диагностика выводит только безопасные коды (`invalid_api_key`, `model_not_found`, `insufficient_quota`, `http_429` и т.п.), не сырой ответ сервиса и не ключ. Доступ модели проверяется отдельно metadata-запросом; это не анализ документа.
