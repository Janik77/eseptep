## Честная граница показа

Это законченный **ручной путь** в реальном Django: план → подтверждённая площадь → материалы → опубликованный учебный прайс → сохранённая смета/PDF → подтверждение состава запроса → тестовая адресная заявка → кабинет поставщика → статус клиента. Данные магазина и цены явно демонстрационные. Внешних email/SMS/WhatsApp, звонков и production-заявок нет.

Реальных запросов OpenAI в этой итерации **0**, расход этой итерации **$0**. Результат и время живого распознавания не измерены; мок не выдаётся за реальный ответ. Доступ к ключу в окружении Windows/cloud и `.env` не найден. Существующий API-код не менялся, автоматическая подмена модели не выполнялась. Ожидание, ошибки и ручное подтверждение доработаны независимо от ключа.

По официальной документации на дату проверки `gpt-4.1-mini-2025-04-14` помечена **Deprecated**, цена входа/выхода `$0.40/$1.60` за 1M токенов. ## PowerShell в терминале PyCharm

Без повторного клонирования. Этот способ безопасен даже при незакоммиченных изменениях в исходной папке: создаётся **соседний worktree**, старые файлы не переносятся/не сбрасываются.

```powershell
Set-Location 'C:\Users\Жаник\Desktop\eseptep'
git status --short
git branch --show-current
git rev-parse HEAD
git fetch origin
git worktree add --detach '..\eseptep-meeting-review' origin/feat/client-meeting-demo
Set-Location '..\eseptep-meeting-review'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\ops\start-meeting-demo.ps1
```

Если ExecutionPolicy запрещает запуск неподписанного скрипта, **не меняйте настройки безопасности**. Выполните эквивалентные команды вручную:

```powershell
$env:DJANGO_ENV='development'
$env:DJANGO_DEBUG='true'
$env:DJANGO_ALLOWED_HOSTS='localhost,127.0.0.1'
$env:ESEPTEP_DEMO_MODE='1'
$env:PLAN_AI_ENABLED='0'
$env:DJANGO_DB_PATH="$PWD\meeting-demo.sqlite3"
$env:DJANGO_PRIVATE_MEDIA_ROOT="$PWD\meeting-demo-private-media"
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_meeting_demo --confirm-isolated
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8220 --noreload
```

Открыть `http://127.0.0.1:8220/projects/upload/`. В PyCharm открыть именно соседнюю папку и выбрать её `.venv\Scripts\python.exe`. При повторном запуске не повторять `worktree add`; открыть существующую демопапку и запустить скрипт. Если папка уже занята другим содержимым, не удалять её: выберите новое имя соседней папки. Для обновления остановить сервер, проверить `git status`, затем `git fetch origin; git switch --detach origin/feat/client-meeting-demo`; только на чистом деморабочем дереве. База/media сохраняются. Seed повторяемый, пароли, сметы, опубликованные редакции и резервы не сбрасывает; при чужих записях отказывается работать.

Учебные логины (это не реальные учётные записи):
- клиент: `demo-client@example.test`;
- поставщик: `demo-supplier@example.test`;
- пароль обоих **только для этого непубличного демостенда**: `Demo-Meeting-2026!`.

Сервер привязан только к127.0.0.1. Демо-режим запрещён при production. Не использовать эти учётные данные на публичном сайте.

## Сценарий встречи на 2–3 минуты

1. Войти клиентом. На главной показать три направления; открыть **«Загрузить проект» → «Открыть учебный план»**. Это обезличенный пример, не работа клиента. На экспликации видна ванная **4,8 м²**.
2. Объяснить отдельное действие **«Разобрать план»**: документ передаётся OpenAI только по этой команде. На этой сборке без ключа показать честное сообщение. В **«Указать ванную вручную»** ввести **4,8**, нажать **«Подтвердить → плитка на пол»**.
3. Нажать **«Рассчитать материалы»**, выбрать **«Комфорт»**. Показать количество к закупке и пояснение округления. Отдельно показать справочный итог и **4 из5 позиций** по учебному прайсу; оставшаяся позиция — **«Цена по запросу»**, не нулевая цена.
4. Выбрать **«Демонстрационная квартира · 36,5 м²»** → **«Сохранить в выбранный проект»**. Площадь квартиры36,5 не подменяет площадь ванной4,8. Открыть **«Скачать PDF»**: это снимок сохранённой сметы, не новый пересчёт.
5. **«Запросить предложение»** → проверить конкретного получателя и список → **«Отправить тестовый запрос»**. Показать номер и статус. Повтор не создаёт вторую заявку.
6. Выйти, войти тестовым поставщиком. Открыть ту же заявку, показать материалы/количество, нажать **«Отметить как просмотренную»**. Вернуться клиентом: статус **«Просмотрена»**. Никакого внешнего сообщения не отправлялось.

Дополнительно: на плитке вручную проверить36,5 м² — ввод, метрика и PDF не должны превращаться в36. Казахская версия доступна **ҚАЗ**, на телефоне заголовок **Саны**, числа с единицами не разрываются. Для плана без площади предусмотрен отдельный пример: ввести5,25 и проверить использование именно этой величины.

## Смена учебного прайса и сохранность

После сохранения сметы можно в **этой же изолированной демопапке** выполнить:

```powershell
.\.venv\Scripts\python.exe manage.py seed_meeting_demo --confirm-isolated --price-version v2
```

Создаётся новая учебная редакция с удвоенными ценами. Старые сметы, PDF и заявки сохраняют прежние суммы и версию. Повтор команды не создаёт дубликаты. Это не команда обновления production-прайса.

## Что не обещать клиенту

Реальное OCR-качество, скорость и стоимость ещё не проверены. Не гарантировать точность строительной методики, наличие/совместимость SKU, конечную цену магазина или сроки работ. Демо-заявки доступны только указанному тестовому поставщику. Коммерческий запуск требует реального прайса/получателей, проверки методики и правил работы с клиентскими документами. Площадь стен автоматически не выводится из площади пола.
