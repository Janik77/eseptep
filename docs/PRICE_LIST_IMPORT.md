# Первый прайс материалов пола

Импорт не публикует цены сам. Он принимает UTF-8 CSV с запятыми, только с указанными ниже четырьмя позициями пилота. Неизвестные материалы остаются без цены. Сверьте с документом магазина и укажите поставщика, номер редакции, дату и источник. Перед импортом сделайте копию базы штатным способом.

| material | unit | Позиция |
|---|---|---|
| laminate | м² | Ламинат |
| underlay | м² | Подложка |
| skirting | м | Плинтус |
| tile_60x60 | м² | Плитка 60 × 60, «Комфорт» |

[Пустой шаблон](floor-price-template.csv) и [заполненный учебный пример](floor-price-example.csv). Скопируйте `floor-price-template.csv` и заполните последнюю колонку подтверждённой ценой в тенге. Если цены нет, уберите строку. Для цены за расчётную единицу оставьте `price_basis=canonical` и пустое `pack_coverage`. Если магазин продаёт только упаковками, укажите `price_basis=pack`, в `pack_coverage` внесите фактическое число м² или м в одной упаковке, а в `price_kzt` цену **одной упаковки**. Колонку `unit` не меняйте. Не выводите площадь упаковки из цены, не подставляйте чужой артикул. Используйте десятичную точку или CSV-кавычки вокруг числа с запятой. Для одной позиции в редакции допустима одна основа цены.

```bash
python manage.py import_floor_prices ./verified-store.csv --store "Название" --version store-2026-11-v1 --source "Подтверждённый документ магазина" --date 2026-11-20
```

Это предварительная проверка без записи. Той же командой с `--write-draft` сохраните новый неактивный черновик. В админке «Прайсы магазина» откройте и проверьте черновик; отдельно выберите его в списке и нажмите «Опубликовать выбранный прайс». Не публикуйте неподтверждённый прайс или учебные числа.

Для общей сметы количество упаковок округляется вверх один раз для совместимой спецификации после объединения комнат. Цена оплаты = упаковки × цена одной упаковки. Пример арифметики: для 51 м² при 2,2 м²/упаковку нужно 24 упаковки. При учебной цене 6 600 ₸ за упаковку выходит 158 400 ₸; при цене 3 000 ₸ за м² на те же 51 м² было бы 153 000 ₸. Разница вызвана только запасом из целых упаковок. Покомнатные суммы показывают долю закупки, не отдельное число упаковок. Отдельные старые калькуляторы не преобразуют цену упаковки в цену за м². Прошлые сметы, заявки и их PDF используют сохранённый снимок; цена ответа магазина может отличаться и показывается отдельно.

## Показ магазина без платного анализа

Откройте существующий проект ESEPTEP в PyCharm с его интерпретатором `.venv`. Запустите **ESEPTEP AI Pilot** и дождитесь адреса `http://127.0.0.1:8233/projects/upload/`. Эта конфигурация использует отдельную учебную SQLite-базу и сохранённое распознавание тестового файла `tests/fixtures/plans/typical-two-room.pdf`. Войдите под демоклиентом, загрузите этот PDF обычной формой и при сохранении выберите проект «ESEPTEP · 72 м²»; для ответа откройте отдельное окно браузера с демопоставщиком. Платный анализ отключён; локальная база и лимит для реальных запросов не меняются. Имена тестовых учётных записей и порядок проверки описаны в `CLOSED_PILOT_STAGE3.md`.
