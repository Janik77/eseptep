# PDF font assets

Unmodified DejaVu Sans and DejaVu Sans Bold from the Debian `fonts-dejavu-core` package, upstream https://dejavu-fonts.github.io/ . Bundled so Windows/Linux export does not depend on installed fonts or a remote font service. Cyrillic, Kazakh and the tenge symbol are included.

See LICENSE.txt: Bitstream Vera license for the fonts, DejaVu additions are public domain. The Debian packaging paragraph does not change the font license.
